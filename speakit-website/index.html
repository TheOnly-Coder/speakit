Get started in 3 steps

  1. 1. Run it. The app needs a small Node.js server (one command: ./speakit.sh start). GitHub Pages hosts this page — the live app runs wherever you host the server.
  2. 2. Register. Open the app URL, create your account, make a server with the + button.
  3. 3. Invite. Share your server's 8-character code. Friends join with it — or add them by username for DMs.

FAQ

Is Speakit the same as Discord?

No — Speakit is its own app with a familiar feel: servers, channels, voice, DMs and friends.

Can this page run the app?

This page is static hosting (perfect for GitHub Pages). The live chat app runs on a tiny Node.js server — see step 1 above.

How do I leave a server?

Open the server, click “Leave …” at the top. Owners can delete a server the same way.

Can I change my profile?

Yes — display name, status, custom status and a custom uploaded avatar, from Settings.
